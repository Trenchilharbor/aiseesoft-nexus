# Aiseesoft Nexus 🎯

## Description
All-in-one **Aiseesoft Nexus** workspace solution featuring document editing, task boards, and real-time team communication.

The goal is a tool that just works — no clutter, no bloat.

## Before you start
- Works on Windows
- Administrator rights for install

## 🗒️ Notes
> [!TIP]
> Keep it updated to get the latest fixes.

## Getting Started
1. Get the latest release from the download section above.
2. Unpack the downloaded archive to a folder of your choice.
3. Run the setup file and follow the on-screen instructions.

## What you get
1. **Calendar & Scheduling:** Built-in planner with recurring events, deadlines, and time blocking.
2. **Document Editor:** Rich-text editing with markdown support, tables, and embedded media.
3. **Analytics Dashboard:** Visual reports on project progress, team workload, and deadlines.
